### Roguelike
Небольшая игра в стиле roguelike использующая lanterna и swing для консольного интерфейса и json для сохранений.
<br>Игра состоит из уровней (всего 21 уровень в игре), в каждом уровне находится 9 сгенерированных комнат, соединённых коридорами.
<br>В каждой комнате могут находиться различные предметы (сокровища/эликсиры/оружие/аптечки/свитки/еда) и различные враги.
<br>Всего в игре 6 различных противников. У каждого свой символ и цвет, характеристики и передвижение.
<br>С каждым уровнем повышается количество противников. Так же имеется система авто-баланса которая добавляет противников на уровень если игроку слишком легко или добавляет полезные предметы (например аптечки или еду) если игроку слишком тяжко.
<br>Комнаты могут быть отделены дверьми. У каждой двери свой цвет и соответствующего цвета ключ.
###Игра
Игра собирается при помощи ./gradlew build и запускается с помощью ./gradlew run

<br>Игрок обозначается знаком "@". Знаком "e" обозначается эликсир (предмет, который игрок может использовать для увеличения характеристик) используя кнопку "K"
<br>Знаком "z" обозначается противник - зомби. Знаки "K" различного цвета представляют ключи для дверей соответствующего цвета. Дверь обозначается знаком "D"
<br>Так же справа обозначаются характеристики персонажа и количество предметов и их тип, которые находятся у персонажа в рюкзаке.
<br>Под ними находится журнал боя, в котором пишется кто нанёс удар/промахнулся.
